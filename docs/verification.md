# Проверка Neon Arena

Среда: Linux x86_64, Python 3.12.14, PyQt6 6.11.0, Qt 6.11.2, PyInstaller 6.22.3.
Интерфейс проверен через Qt offscreen.

| Проверка | Результат |
|---|---|
| Ruff | Проверка и форматирование прошли |
| unittest | 36 тестов, все успешно |
| Движение и бой | Нормализация движения, рывок, неуязвимость, урон, два оружия, пробивание |
| Геометрия | Границы, препятствия, столкновения отрезка с целью и стеной |
| Враги | Стрелок целится при отступлении, таран показывает направление и атакует |
| Волны | Все враги и отложенные спавны должны закончиться перед улучшением |
| Улучшения | Все восемь эффектов, переход к следующей волне, проверка недоступного выбора |
| SQLite | CRUD профилей, фильтры, атомарная запись, уникальный забег, каскад, перезапуск |
| Qt | Клавиатура, мышь, настройки, кнопки, координаты при изменении размера, возврат в меню |
| Автоматический сценарий | Защищённый от урона бот зачистил волны 1 и 2, дошёл до волны 3 |
| Сборка Linux | PyInstaller завершён; --smoke-test упакованной программы вернул код 0 |

Защита бота нужна только для проверки переходов и получения скриншотов;
в обычном режиме бесконечной неуязвимости нет.
Физическое прослушивание WAV не выполнено: в контейнере нет аудиоустройства.
При отсутствии устройства Audio отключает эффекты, игровой процесс продолжается.

Windows .exe собран и запущен. Предусмотрены spec, BAT и GitHub Actions.
Перед сдачей нужно интерактивно проверить целевой Windows: звук, полный экран,
переходы между волнами, результат и сохранение. Linux графический запуск через
X11 в контейнере не проверен; в среде отсутствует libxcb-cursor.so.0.
